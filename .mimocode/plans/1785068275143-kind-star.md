# SubAgent 功能实现计划

## Context

TAgent-Desktop 2.0 当前只有单会话的 Pi Agent / kscc 核，没有 subagent 机制。用户要求实现 subagent（任务分解，非看板实体）。

**核心区分**：SubAgent ≠ Kanban Worker。SubAgent 是轻量任务函数（spawn → 干活 → 返回结果 → 销毁），不是独立会话实体。

## 现状

- `packages/shared/types/agent.ts` 已有 `AgentDefinition`（行 207-220）：description / tools / disallowedTools / prompt / model / maxTurns
- `AgentEvent` 已有 `task_started` / `task_progress` / `task_notification` 事件类型（行 685-711）
- `SDKToolProgressMessage` 已有 `task_id` 和 `subagent_type` 字段（行 446-455）
- `AgentProviderAdapter` 无需改（subagent 是 adapter 内部实现细节）
- **kscc SDK 原生支持 subagent**：`agents` option + `forwardSubagentText` + `agentProgressSummaries`
- **Pi Agent 不原生支持 subagent**：需要自己实现（spawn 子 Agent 实例 + 限制工具 + 收集结果）

## 实现方案

### 分两条路线

**路线 A：kscc 核 subagent（SDK 原生，简单）**
SDK 内部处理 spawn / 执行 / 结果收集。我们只需：
1. 传 `agents` 选项给 SDK query
2. 开启 `forwardSubagentText: true`（完整嵌套对话）
3. 开启 `agentProgressSummaries: true`（进度摘要）
4. 渲染层处理 `parent_tool_use_id` 嵌套显示

**路线 B：Pi 核 subagent（自实现，中等复杂度）**
Pi Agent 没有 subagent 内置机制。我们通过 beforeToolCall 拦截 `task` 工具调用，在主进程内创建子 Agent：
1. 注册自定义 `task` 工具（Pi AgentTool）
2. 主 Agent 调用 task → beforeToolCall 拦截
3. 创建子 Pi Agent（复用 PiAdapter.createSession 逻辑，但限制 tools + 自定义 prompt）
4. 子 Agent 执行 → 收集结果
5. 结果作为 tool_result 返回主 Agent

关键设计：
- 子 Agent 是独立 Pi Agent 实例（内存，无进程）
- 工具集限制：explore 只读（Read/Glob/Grep/Bash），general 全量
- 结果收集：遍历 AgentEvent，提取 text 内容拼成结果
- 不需要 IPC/渲染层参与（子 Agent 结果直接返回主 Agent）

#### 6. 渲染层：subagent 输出嵌套显示

**文件：** `apps/electron/src/renderer/components/chat/Chat.tsx`

在 `piEventToSdkMessages()` 转译中，subagent 消息带 `parent_tool_use_id`。渲染层需要：
- `parent_tool_use_id !== null` 的消息 → 缩进显示（嵌套在父 tool_use 下）
- `task_started` → 显示 "子代理启动: {description}"
- `task_notification` → 显示完成状态 + 摘要
- 子代理的 text/thinking blocks → 缩进显示

当前 `piEventToSdkMessages()` 全部 `parent_tool_use_id: null`（Pi 核不支持嵌套）。kscc 核 SDK 自动设置。

对于 Pi 核 task 工具：结果作为 tool_result 返回，不需要特殊渲染（跟普通工具一样）。

### 实现顺序

1. **kscc 核 subagent（简单）**：buildSdkOptions 加 agents + forwardSubagentText → 验证 SDK subagent 能跑
2. **内置子代理定义**：创建 subagent-definitions.ts
3. **Pi 核 task 工具**：创建 subagent-task-tool.ts → 注册到 Pi Agent tools
4. **渲染层**：Chat.tsx 处理 parent_tool_use_id 嵌套 + task_* 事件
5. **session-service 透传**：buildQueryOptions 传 agents
6. **typecheck + build**

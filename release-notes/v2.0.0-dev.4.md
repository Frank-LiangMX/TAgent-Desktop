# TAgent v2.0.0-dev.4 更新

> 开发预发布版（dev.4）。全局浮岛布局（AppShell）+ 多会话标签栏，对齐 TAgent_General 桌面版视觉与交互。
> 未打 tag、未触发 CI 发版构建；仅供本地 dev 验证。

## 新功能
- **全局浮岛布局（AppShell）** — main 在底层透 scene，rail（左导航轨）+ sidebar（会话列表）作为玻璃浮岛浮在上面，顶栏 absolute 浮顶。flex 行布局 + 玻璃材质（navigation/panel fill 用 glass-rgb 直接拼避开 Electron calc 嵌套解析失败）。见 `components/AppShell.tsx`、`styles/app-shell.css`。
- **Rail 左导航轨** — 玻璃胶囊浮岛，上下两胶囊拆分（上：logo/会话/主题，下：设置），中间透 scene。phosphor 图标（Sparkle/ChatsCircle/Palette/GearSix，size:18 weight:regular，对齐旧版 RAIL_ICON）。见 `components/Rail.tsx`。
- **多会话标签栏（TabBar）** — 像浏览器 tab，一窗口开多会话标签，点 tab 切、× 关。标签栏顶部和 rail/sidebar 顶对齐（同一 band 基线）。见 `components/TabBar.tsx`、`atoms/tabs.ts`。
- **切换滑动动画** — 选中态用滑动底板（active-plate）：JS 测 active tab 位置驱动 transform/width，切 tab 时底板平滑滑动（对齐旧版 updateActivePlate）。tab 本身选中时透明，只 primary 文字/icon。
- **SessionSidebar 玻璃面板** — 改 `.app-nav-sidebar` 玻璃浮岛（去 border-r，圆角 22 + panel-blur + scene 透出）。
- **顶栏浮顶** — absolute 浮顶 + blur 24 + 玻璃底，渠道管理/WorkspaceSelector/ThemeSettings 重排进去。

## Bug 修复
- **输入框位置出画** — main 改 flex flex-col，TabBar shrink-0，Chat 在 TabBar 下方 flex-1，composer 不再出画。
- **rail/sidebar 顶底对齐 + 输入框底对齐** — 去 rail padding 让胶囊顶底和 sidebar 齐平；composer bottom 对齐 nav 底（band-inset-bottom）。

## 其他优化
- **图标** — 装 `@phosphor-icons/react@2.1.10`（electron devDep），rail/tab 图标换 phosphor 对齐旧版风格（ChatsCircle 等）。
- **工程** — globals.css 加浮岛几何 token（rail/sidebar/gap/band-inset）；app-shell.css 加 tab 栏样式（strip/tab/选中态/plate/close/状态点）。

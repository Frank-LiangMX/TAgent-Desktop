# TAgent v2.0.0-dev.4 更新

本次更新聚焦于会话工作台、Agent 执行稳定性、消息展示和文件工作流体验。

## 会话工作台

- **更清晰的会话时间线** — 优化轮次模型、思考过程、运行状态和完成状态的展示。
- **长会话体验** — 改进滚动定位、补页加载、会话切换和运行中消息的稳定性。
- **会话进程管理** — 减少重复启动后台进程，提升会话恢复和后台运行状态的可靠性。
- **会话摘要与文件审阅** — 增加会话摘要入口，并改进文件变更和审阅差异展示。
- **附件与预览** — 图片附件可保留在会话历史中；HTML 文件支持安全预览。

## Agent 执行

- **无进展检测** — Agent 长时间重复尝试或没有有效推进时，会主动提示用户介入。
- **子代理展示优化** — 改进子代理入口识别，避免嵌套任务被错误展示。
- **运行中引导** — 优化运行中的追加指令、停止操作和消息队列处理。
- **时间统计修正** — 统一思考时间、运行时间和完成状态的显示。

## 交互与外观

- **消息区域优化** — 放宽消息内容区域，提升长文本和代码内容的可读性。
- **侧栏信息优化** — 改进侧栏分组、文件路径、轮数和会话状态展示。
- **运行状态提示** — 增加会话已打开但当前未聚焦的状态提示。
- **滚动导航** — 优化滚动缩略图、滚动位置保持和长内容导航。
- **界面细节** — 改进标题栏状态提示、确认弹窗、用户提问、设置页面和主题化 Tooltip。

## 修复

- 修复消息发送后偶尔跳回上一轮的问题。
- 修复运行完成后内容折叠和消息动画状态不一致的问题。
- 修复长内容滚动时定位丢失的问题。
- 修复文件预览、文件变更审阅和路径标签的显示问题。
- 修复多个图标导入和弹窗布局问题。
- 修复部分会话状态在重新打开后无法正确恢复的问题。

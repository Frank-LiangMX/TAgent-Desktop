# TAgent v2.0.0-dev.5 更新

本次更新聚焦于会话工作台、记忆沉淀、Agent 执行稳定性、长会话体验和消息展示细节。

## 会话工作台

- **频繁切换会话提醒分屏** — 检测到用户在多个会话之间频繁切换且尚未使用分屏时，提示开启分屏工作台；确认后自动进入左右分屏。
- **记忆沉淀链路增强** — 完善记忆证据收集、空闲整理、会话级落盘和持久化调度，降低“有记忆系统但长期不沉淀”的情况。
- **长会话体验** — 发送新一轮消息时预留输出空间；历史消息补页后保持原滚动位置；长会话历史加载更平滑。
- **工作台与会话状态** — 改进分屏 Dock、标签、会话切换、运行状态和队列交互。

## Agent 执行

- **受限浏览器** — Agent 可以在独立的浏览器标签页中打开网页、阅读页面、点击、输入和滚动；遇到登录或验证码时，用户可以接管操作，完成后继续任务。
- **长时间任务后台运行** — 长时间编译、开发服务器等任务可以继续在后台运行，并在当前会话中查看运行状态。
- **本机工具与环境兼容性提升** — 改进本机辅助工具的能力识别和路径处理，提升不同安装环境下的可用性。
- **思考过程展示** — 对较长的思考过程进行整理和折叠，减少重复内容，让阶段、结论和下一步更容易查看。
- **任务结果状态** — 更清楚地区分完成、中断、出错、等待后续任务和缺少最终答复，避免任务结束后留下无状态的空壳回答。
- **子任务与时间线** — 子任务入口和时间线展示更稳定，展开后可以查看阶段细节和实时状态。

## 交互与外观

- **滚动导航** — 滚动刻度避让运行计时和输入区域，长内容导航和滚动位置管理更稳定。
- **消息展示** — 中文 Markdown 语境下统一常见半角标点；文件路径芯片和消息内容展示更清晰。
- **主题与选择体验** — 文本选区颜色跟随主题，界面细节在不同主题下保持一致。

## 修复

- 修复流式消息被输入框遮挡、首次落盘思考消息被吞以及滚动到底判断不准确的问题。
- 修复文件路径芯片相对正文下沉以及 g/p/q 等下行字母被截断的问题。
- 修复子任务入口重复展示、长思考内容重复堆叠和任务结束后显示空壳完成状态的问题。

# TAgent v2.0.0-dev.5 更新

> 开发预发布版（dev.5）。超长会话虚拟化 + 顶栏清理 + 自定义窗口栏 + 会话轮数标注。
> 未打 tag、未触发 CI 发版构建；仅供本地 dev 验证。

## 新功能
- **超长会话虚拟化** — 只渲染最近 20 条，旧消息空闲帧递增补齐（40/批），防超长会话卡顿。底部对话区永远全量渲染 + 流式实时追加 + 自动钉底（对话丝滑零损耗）。顶部"正在加载更早的 X 条"提示常驻（说清楚 + 不闪）。`scrollReady` 门控（分批期间不恢复滚动，全挂完才恢复，无动画干扰）。见 `Chat.tsx`。（待超长会话实测）
- **自定义窗口栏** — `titleBarStyle: hidden`（Windows 隐藏系统栏）+ 自定义 `WindowControls`（最小化/最大化/关闭 SVG 按钮，close hover 红色）+ 主进程 IPC（window:is-maximized/minimize/maximize/close/resize）+ preload 暴露。对齐 TAgent_General。见 `components/WindowControls.tsx`、`main/index.ts`。
- **会话轮数标注** — `AgentSessionMeta.turnCount`，发 user 消息时增量 +1（不重读 JSONL），SessionSidebar 副行显示"X 轮"。见 `session-service.ts`、`SessionSidebar.tsx`。（旧会话无 turnCount 显示空）

## 变更
- **顶栏清理** — 顶栏保留为单独一行（窗口栏，40px 浮顶 + 下方 16px 间隙 + nav），但内容清空（渠道/主题移 rail）。对齐旧版顶栏"安静"（只系统 chrome）。
- **渠道/主题移 rail** — rail 加渠道图标（PlugsConnected，开 ChannelManager）+ 主题入口（ThemeSettings 改 rail 图标样式）。顶栏不再放渠道/主题/WorkspaceSelector。
- **AppShell 顶栏** — 始终渲染顶栏条（含 WindowControls），scene padding-top:40px 占位，nav margin-top:band-inset-top 间隙。

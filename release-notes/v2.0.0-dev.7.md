# TAgent v2.0.0-dev.7 更新

> 开发预发布版（dev.7）。工具循环基础设施：工作区 MCP store + 权限审批 service + PermissionBanner。
> 两核接通（tools/mcp/canUseTool/permissionMode）留下轮。未打 tag、未触发 CI。

## 新功能
- **工作区 MCP config store** — `main/lib/mcp/mcp-store.ts` 读写 `~/.tagent[-dev]/projects/{slug}/mcp.json`（WorkspaceMcpConfig CRUD + getEnabledMcpServers），复用 shared McpServerEntry/WorkspaceMcpConfig。`main/lib/ipc/mcp-service.ts` 注册 IPC（GET_MCP_CONFIG/SAVE_MCP_CONFIG/TEST_MCP_SERVER）+ preload 暴露。
- **权限审批 service** — `main/lib/permission/permission-service.ts`：pendingPermissions Map + createCanUseTool（kscc SDK 签名）+ createBeforeToolCall（Pi 签名）。共享逻辑：bypass 全放行 / auto 只读静默放行（isAutoModeAutoAllowTool）+ 写操作弹框 / plan 只读放行写拒绝。危险命令（isDangerousCommand）标记。复用 shared permission-rules。会话白名单（始终允许）。IPC PERMISSION_REQUEST（推 renderer）+ PERMISSION_RESPOND（回）+ preload 暴露。
- **PermissionBanner** — `renderer/components/permission/PermissionBanner.tsx`：motion 弹确认横幅（工具名 + 参数 + 危险标记 + 允许/拒绝/始终允许），挂 Chat composer 上方。30s 超时自动拒绝。

## 变更
- shared 加 PERMISSION_REQUEST 通道名（agent.ts）；复用已有 GET_MCP_CONFIG/SAVE_MCP_CONFIG/TEST_MCP_SERVER/PERMISSION_RESPOND/UPDATE_SESSION_PERMISSION_MODE。

# TAgent v2.0.0-dev.6 更新

本次更新聚焦于协作会话、自动化任务、Agent 执行稳定性、记忆质量和桌面工作台体验。

## 协作会话

- **Fusion 协作流程** — 完善协作房间、成员会话、任务执行和结果回传流程，让多个 Agent 可以围绕同一个目标协同工作。
- **协作任务生命周期** — 增加运行中取消、用户确认后继续、失败状态和中断信号处理，减少协作任务卡在中间状态。
- **跨设备交接准备** — 完善协作房间的访问控制、邀请、证书和网络开关，为受控的跨设备协作提供基础。
- **协作工作台** — 改进房间列表、成员状态、运行进度、结果摘要和待处理任务的展示。

## 自动化与任务执行

- **自动化任务** — 增加自动化任务的创建、编辑、启停、调度和运行状态展示。
- **后台任务** — 长时间任务可以继续在后台运行，当前会话可以查看任务状态和结果。
- **执行模式增强** — 改进自动计划、计划步骤信号和无进展检测，让 Agent 在重复尝试或缺少有效推进时更早暴露状态。
- **会话恢复** — 优化会话启动、进程复用、历史恢复和异常结束后的状态收束。

## Agent 能力

- **浏览器能力增强** — 改进浏览器标签页控制、页面交互、滚动和主进程通信，提升 Agent 阅读和操作网页时的稳定性。
- **附件处理** — 改进图片、文档和其他附件进入 Agent 上下文的方式，保留更完整的文件信息和处理结果。
- **多后端协作** — 完善内部 Agent 后端与外部工具成员的适配和生命周期管理。
- **工具权限与中断** — 改进工具调用、用户确认、中断和失败回传，减少运行结束后留下空状态的问题。

## 记忆与长期运行

- **记忆质量评估** — 增加记忆候选质量判断，降低低价值、重复或缺少依据的内容进入长期记忆。
- **记忆检索** — 改进记忆范围、相关性排序和检索结果组织，让不同会话和工作区之间的记忆边界更清楚。
- **沉淀调度** — 优化证据收集、阶段队列、空闲整理和复盘流程，提升长时间使用后的记忆沉淀稳定性。
- **用户提醒** — 改进记忆整理相关的提醒和队列状态展示，减少后台处理过程中的无反馈感。

## 工作台与交互

- **会话工作台** — 改进标签、分屏、侧栏、启动状态和会话路由，切换多个任务时更加稳定。
- **消息时间线** — 优化过程、阶段、思考、工具调用和最终结果的组织方式，长内容更容易阅读。
- **运行状态** — 更清楚地区分准备中、运行中、等待用户、已完成、中断和失败等状态。
- **界面稳定性** — 修复部分滚动位置、消息布局、附件展示和窗口启动过程中的视觉抖动与状态错位。

## 修复

- 修复协作任务取消后成员会话仍保持运行状态的问题。
- 修复长会话历史恢复、流式消息收尾和任务结果展示中的状态不一致问题。
- 修复浏览器控制和附件处理过程中部分 IPC 状态未正确回传的问题。
- 修复自动化任务调度、后台运行和异常退出后的状态清理问题。
- 修复记忆候选重复、范围判断和检索结果不稳定等问题。
- 修复若干会话切换、分屏工作台、消息滚动和界面布局问题。

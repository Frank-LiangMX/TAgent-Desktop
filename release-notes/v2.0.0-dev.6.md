# TAgent v2.0.0-dev.6 更新

> 开发预发布版（dev.6）。会话 sidebar 重构（motion 丝滑动效）+ 三点菜单（重命名/置顶/删除）+ 打开项目按钮。
> 未打 tag、未触发 CI 发版构建；仅供本地 dev 验证。

## 新功能
- **会话 sidebar 丝滑动效（motion/Framer Motion）** — 列表项 `layout` spring 平滑重排、选中指示条 `layoutId` 在项之间平滑滑动、`AnimatePresence` 新建/删除弹性进出 + 其他项让位、组折叠 height spring 展开、组头箭头 rotate spring。替代之前生硬的 CSS keyframes。见 `SessionSidebar.tsx`。
- **三点菜单（重命名/置顶/删除）** — 会话项 hover 显竖向三点菜单：重命名（inline input 编辑 title）、置顶（togglePin + 置顶图标）、删除（confirm + 乐观移除 + exit 动画）。主进程加 `UPDATE_SESSION_META` + `TOGGLE_PIN` IPC，preload 暴露 `updateSessionMeta`/`togglePin`。见 `SessionSidebar.tsx`、`session-service.ts`、`preload/index.ts`。
- **打开项目按钮** — sidebar 顶部"新建会话"旁加 FolderOpen 图标按钮（创建工作区）。WorkspaceSelector 移除（工作区切换不需要）。
- **会话项样式重构** — hover/选中 primary tint 实色 + 过渡（color/bg/border 160-200ms cubic-bezier）、字号层次（标题12px/600、副行9px 模型+时间、轮数移标题旁）、ChatsCircle 图标（选中 opacity-80 primary）、组头 CaretRight + count badge。

## 修复
- **副行规律** — 模型（左 truncate）+ 时间（右 ml-auto）两项，轮数移标题旁（不再三项挤一行）。
- **指示条歪斜** — `layoutId` 指示条改 `top/bottom inset` 撑高度（不用 translate 居中），避免和 motion layout transform 冲突歪斜。
- **三点让位** — 三点菜单 absolute 右侧（不占 flex 流），内容 pr-7 预留，hover 出现不挤。

## 变更
- **依赖** — 加 `motion@12.42.2`（Framer Motion，丝滑动效）。
- **CSS** — agent-thread.css 撤掉生硬的 enter/exit/indicator-in keyframes + grid-template-rows 折叠（motion 接管）。

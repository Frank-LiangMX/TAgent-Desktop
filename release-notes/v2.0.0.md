# TAgent v2.0.0 正式版

TAgent 2.0 将 AI 会话、资料收集、任务排期、知识积累和工作报告串联到同一个桌面工作空间。本次正式版整合多内核运行能力，升级个人工作台与 WPS 工作流，并改进自动化执行、会话恢复和日常交互体验。

## 本次亮点

- **统一个人工作台**：从记录想法、收集资料，到安排待办、沉淀知识、生成报告，在一个入口完成。
- **日期任务与甘特图**：按日期查看待办，设置跨天任务，直观掌握任务跨度与完成进度。
- **日报、周报集中管理**：完整阅读正文，管理草稿与定稿，查看来源、版本及生成时间。
- **WPS 工作流**：读取已授权的工作沟通与云文档活动，整理报告，并按要求创建 WPS 云文档。
- **多内核与渠道选择**：分别选择 Agent 内核、兼容的 API 渠道和模型，支持会话内手动切换。
- **更连贯的桌面体验**：统一玻璃材质，补充过渡动效，优化流式回复、错误提示与恢复操作。

## 个人工作台

- 重新组织“今天、收集、日程、知识、日报与周报”五个主要入口；完整待办列表、每日足迹等功能通过“更多”进入。
- 随手记录想法、收藏链接或保存工作进展，支持项目、标签与日期筛选，以及编辑、置顶、归档、回收站和恢复。
- 收集卡片统一展示随笔灵感、链接资料与工作进展，支持展开全文及查看原始来源。
- 整理前先保存原文；交给 Agent 时可填写修改要求或补充信息，减少原始记录与整理成果之间的脱节。
- 将知识入口整合进工作台，改进跨知识库搜索、主题标签筛选、正文阅读、编辑及未保存修改保护。
- 日常随笔、个人安排与工作成果分别处理，减少个人记录混入工作日报的情况。

## 待办、日程与任务甘特图

- 待办列表跟随所选日期筛选，同时保留“全部日期”查看方式；未排期任务单独列出。
- 新建待办默认使用当前选中的日期，跨天任务可直接填写开始日期和结束日期，也可进一步精确到时间。
- 自动计算计划持续时间，支持填写实际完成进度；进度达到 100% 时同步标记完成，调低进度可重新打开待办。
- 新增按周、按月查看的日期甘特图，展示跨天、跨月任务的计划区间与完成进度，点击任务即可调整排期。
- 优化甘特图的月度刻度、任务信息、当前日期提示和空状态，常规桌面宽度下可完整查看整个月。
- 日程支持周视图、月视图及独立时间段，可关联已有待办；排期与任务完成状态分别管理。
- 周概览、待办列表和日历同步识别任务起止区间，跨天待办在覆盖的每一天均可查看。

## 日报、周报与 WPS

- 新增独立的“日报与周报”文档入口，将报告正文与“每日足迹”中的历史操作分开展示。
- 报告支持完整阅读、编辑、保存和定稿；同一日期、同一项目的日报版本集中管理，再次生成时保留已有版本。
- 列表与正文显示具体生成时间，有修改时另显示最近更新时间；版本列表展示完整日期与时间。
- 工作记录与报告保留来源关联，方便回看原文、核对信息并继续补充。
- 连接本人 WPS 365 账号后，可按授权范围查询聊天原文、搜索消息及采集云文档活动，为报告整理提供依据。
- 支持设置每日工作日报任务，生成带来源的报告草稿，也可手动生成当天报告。
- 在 Work 模式下，可要求 Agent 将整理好的日报或周报创建为 WPS 智能云文档，并返回文档链接或文件标识。
- 增加云文档创建去重与异常结果核对，减少重复创建。
- WPS 配置统一收纳至“工作台 → 日报与周报 → WPS 连接与自动化”。

## Agent 内核、模型渠道与协作

- 明确 Pi、Codex、Claude Code 的运行内核选择，将内核与 API 渠道、模型配置分开管理。
- 模型选择按内核兼容性筛选，优化选择弹窗与滚动体验，减少渠道、模型和实际执行路径不一致的问题。
- 支持会话内手动切换内核，保留宿主聊天记录，并向目标内核交接可见历史。
- 改进工具调用、图片附件、多轮对话及运行结果的传递。
- 统一子代理委派的并发控制、工具能力、模型选择与后台结果回传。
- MoA 席位支持分别绑定渠道，完善多模型讨论的配置与执行。
- 改进协作任务取消、失败重试和中断后的状态展示与恢复处理。

## 自动化与视频资料分析

- 自动化任务新增“立即运行”，支持暂停任务临时执行一次，并保留原有启停状态和下一次计划时间。
- 避免同一任务重复并发执行；任务状态等待 Agent 实际执行结果，减少提前显示完成的情况。
- 改进自动化任务异常结束与状态清理，以及 WPS 日报的补报处理。
- 新增视频链接分析工具，可提取关键画面与可用字幕，辅助摘要和内容理解。
- 新增本地语音引擎与 Whisper 模型配置，按需下载后可尝试对视频音频进行本地转写。
- 区分画面分析、字幕和语音转写的依据，缺少音频信息时明确说明。

## 界面与稳定性

- 工作台导航、记录卡片、知识文档、报告列表、日历和甘特图统一采用全局玻璃材质，随主题调整透明度、高光与阴影。
- 增加栏目切换、卡片进入、悬停和按下反馈，遵循系统“减少动态效果”设置。
- 合并碎片化进度文本，改进过程信息与最终正文的组织方式，减少重复刷新和刷屏。
- 修复部分流式内容丢失、序号与标点展示异常，以及上游错误被误判为正常完成的问题。
- 改进断线重连、错误提示和显式恢复操作，优化会话启动、停止、进程回收与重新打开后的状态处理。
- 修正部分上下文容量与用量展示，改善消息滚动、模型选择和长内容阅读体验。

## 升级与使用说明

- **KSCC 接入方式调整**：KSCC 改为内置 HTTP 网关渠道，移除原本的本机 CLI 通路；原有用户需在渠道设置中确认连接配置。
- **班组编排调整**：旧的班组编排暂停，已有看板数据保留并可查看；任务委派可使用子代理能力。
- **内核切换边界**：切换通过可见历史交接上下文，不迁移隐藏推理、正在执行的工具或完整原生状态；不同内核仍需使用兼容的渠道与模型。
- **WPS 授权要求**：消息、文档采集受本人可访问范围与平台授权限制；创建云文档需应用开通相应权限并完成本人授权。本次未接入 WPS 日历同步。
- **本地调度要求**：自动化依赖桌面应用运行，应用退出期间不会持续执行。
- **视频分析要求**：实际能力受视频来源访问条件、本地处理工具与语音模型准备情况影响，受限或需要登录的平台不保证可直接读取。

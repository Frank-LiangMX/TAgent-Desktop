# TAgent v2.0.0-dev.2 更新

在 `dev.1` 公开预发布之上：多模型协作（会诊 / 圆桌）、本机 CLI 工人池、无进展防死循环，以及一波聊天与安装体验打磨。

## 新功能

### 多模型协作（MOA）

- **会诊** — 多席并行交卷再汇总；班底双档（kscc 内网 / 外部渠道），发送旁一键触发。
- **圆桌** — 多角色多轮研讨、纪要与收敛，支持插话与喊停。
- **设置 · MOA** — 会诊与圆桌对等双子模块，**共用一套班底**；圆桌可配默认轮数、`@` 深度、讨论中输入路由。

### 无进展防死循环（No-Progress Guard）

- 拦截反复无进展的工具空转，在撞上 `maxTurns` 前：**提醒 → 强制复盘 → 软暂停**。
- 默认 **`enforce`**；可用设置或环境变量切到 `shadow` / `off`。
- 设置页可调守卫模式；状态栏反馈 warn / pause。

### 本机 CLI 子代理工人池

- **动态工人池** — 启动自动探测，只列本机实际装上的 CLI。
- **已支持 runner**：kscc / grok / codex / mimo / **opencode** / **Claude Code（claude）** 等（按探测结果显示）。
- **能力画像** — 成本 / 推理 / 视觉 / 适用场景可编辑；`require` / `prefer` 路由 + 能力卡注入主 Agent。
- **会话级工人选择** — composer 可选 `cliWorkerId`，注入 task 路由。

### 聊天与界面

- 过程折叠、文件预览、AskUser、多 speaker 消息布局。
- 会话状态色点：待选择 pending、正在看感知绿点（Tab / Dock / 侧栏同源）。
- 正文阅读节奏对齐（约 15px、字体栈与 prose 对比度微调）。
- Windows 安装器品牌层（图标 / 侧栏等 NSIS 资源）。

## 体验优化

- **过程显示** 默认简洁（`concise`）；旧本地 `full` 偏好用 v2 键迁移，避免被旧值钉死。
- **分屏工作台** 默认开启（设置可关）；旧关闭偏好用 v2 键迁移。
- 侧栏「打开中」只跟**当前可见**会话，不再被隐藏 tab 误亮。
- 会话区左侧留白加大，避开滚动小地图遮挡。
- 外观页「加载动画」图鉴暂时隐藏（开关保留，发版后再露）。
- Markdown / 输出风格去掉装饰性 emoji 红线。

## Bug 修复

- **附件进核** — 修复「气泡有附件、模型看不到」：发送时把附件绝对路径注入 prompt，图片额外打成多模态 image block（kscc）。
- **GLM 流式收尾** — 回合结束时保留已流出的回复，避免尾部被清空。
- **发送队列** — 引导延后到 loop 停稳再 flush；用户停止按中断而非 error；支持引导 / 立即发送 / 编辑。
- **CI** — typecheck（含 shared 去掉 Node 全局依赖）与 resolve-backend 测试在无本机 `kscc` 的环境可过。

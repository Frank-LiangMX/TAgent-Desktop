# TAgent v2.0.0-dev.2 更新

> 开发预发布版（dev.2）。从 dev.1 的"能对话骨架"推进到"可配置多渠道 + 按项目工作区 + kscc 核与 Pi 核均可跑"。
> 未打 tag、未触发 CI 发版构建；仅供本地 dev 验证。

## 新功能
- **渠道管理** — 渠道 CRUD（`channels.json`）+ API Key 加密（Electron safeStorage）+ 启动 seed `kscc-internal` 内置渠道（OAuth，不可删）+ 渠道管理 UI。
- **工作区** — 项目目录=工作区，数据对齐 kscc 模式 `projects/{sanitizedPath}/`；打开项目目录创建/切换工作区，会话 JSONL 按项目分目录存储。
- **Pi 核接入（@tagent/pi-core）** — 可复用 Pi 内核库（kscc bare / HTTP 直连 streamFn、antml 协议、工具、权限、Xfast、MoA、MCP 桥）；`pi-agent-adapter` 重写为常驻 Agent + AgentEvent→SDKMessage 转译。
- **双核会话服务** — 按 channelId 选核 + 会话绑核（kscc↔external 互斥，核内换模型自由）+ workspace-aware 持久化 + cwd 解析为项目目录。
- **会话持久化** — JSONL 落盘 + resume 续历史（kscc 核首条 spawn 带 `resumeSessionId`）。
- **IR 渲染层（重写，双核统一）** — `sdkMessageToIR` 统一转译，renderer 拆 `ContentBlockView`/`ToolResultView`/`ChatInput`。
- **会话列表侧栏** — 按工作区分组的会话列表 + 切回会话读 JSONL 加载历史。

## Bug 修复
- **SessionSidebar** — `listSessions` 返回非数组时防御 + 主进程日志。

## 其他优化
- **构建** — 新增 `build:pi-core`（ESM 单独打包，外部化 pi-ai/pi-agent-core/MCP）；main bundle 外部化 `@tagent/pi-core`/`pi-agent-core`/`pi-ai`。
- **工程** — pi-core 补 `typecheck` 脚本 + `typescript` devDep，纳入工作区 `bun run typecheck`（5 包全绿）；`.gitignore` 增 `*.bak`/`*.tsbuildinfo`/嵌套 pi-core 重复目录。

# TAgent v2.0.0-dev.1 更新

TAgent 2.0 首个公开预发布版本。新架构骨架：双核可拔插 + 会话进程长驻 + 模块化 monorepo。

## 新功能

- **双核可拔插** — kscc 核（内网渠道）+ Pi 核（外部渠道），按渠选核，对外版可不装 kscc。
- **会话=进程长驻** — 开一个会话 spawn 一个进程，常驻直到退出，多轮复用不重放历史。
- **子代理（SubAgent）** — 内置 code-reviewer / explorer / researcher，支持并发执行与模型路由。
- **Cursor 式运行容器** — 阶段工作块简洁时间线，运行态可视化。
- **富内容分屏预览** — 代码 / 图片 / 文件分屏预览，侧栏可见会话列表。
- **上下文容量按模型显示** — 实时展示 token 用量与模型上下文窗口对比。
- **文件查找增强** — 模块化文件查找，支持超大目录跳过与源码优先扫描。
- **自动更新** — Electron 应用内检查更新与自动升级。
- **输入区控件收敛** — 权限模式 / 模型选择 / 项目绑定集中于输入区 footer。
- **权限模式运行中切换** — auto / bypass / plan 三模式 Popover pill。
- **文件预览** — 会话内文件 chip 点击预览。
- **真实渠道检测** — 外部 Provider 连接测试和模型列表拉取改为真实 HTTP 请求。

## 体验优化

- **简洁时间线** — concise 模式下过程区轻量逐步可见，自动折叠已完成阶段。
- **流式输出硬化** — 单真源流式 + idle 看门狗 + 权限超时倒计时，消除闪空与重复。
- **会话渲染硬化** — 条件拆分消闪空、子代理进度、输出克制。
- **侧栏改进** — 工作区和时间线独立折叠，搜索及活动会话自动展开。
- **运行计时跨会话保持** — 侧栏切换主区跟随。
- **Windows 兼容** — 全平台路径处理与原生模块对齐。

## 基础设施

- **核心回归测试** — 覆盖会话标签、渠道协议、会话元数据和 JSONL 重载恢复（74 文件 / 739 测试）。
- **桌面打包** — electron-builder 三平台（Windows / macOS / Linux）打包与 CI 门禁。
- **权限规则体系** — PermissionService 白名单精确 key + 危险命令拦截。

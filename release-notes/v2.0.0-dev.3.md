# TAgent v2.0.0-dev.3 更新

> 开发预发布版（dev.3）。会话页面 UI 细化 + 主题系统，对齐 TAgent_General 桌面版视觉风格（干净重写，不搬其屎山 CSS）。
> 未打 tag、未触发 CI 发版构建；仅供本地 dev 验证。

## 新功能
- **主题系统** — 6 色系（default/ocean/forest/slate/orange/purple）× 浅/深/跟随系统切换；localStorage 持久化 + matchMedia 系统明暗监听。token 底座复用同库 tokens.css（12 套 .theme-* class 已预生成，0 token 工作量），机制纯 CSS class 切换。见 `atoms/theme.ts`、`ThemeInitializer`、`ThemeSettings`。
- **scene 主题背景** — 会话页背景换成主题 scene 弥散场（三光斑径向渐变），换主题背景自动换色。用 `--scene-*-rgb` 直接拼不嵌套 color-mix（绕开 Electron 对多层 color-mix+calc 解析失败的坑）。
- **composer 玻璃浮岛** — 输入框浮岛布局（消息从下方滚过透出）+ 玻璃质感（透明底 + scene-a 顶光 + blur + 顶高光 + 向下柔影 + 聚焦三层 ring），对齐 TAgent_General chat-input-glass。
- **用户气泡** — 中性玻璃板 + 右下尖角 + 顶高光 + 向下柔影，调实 fill 在 scene 上有边界。
- **模型名胶囊** — assistant 消息 9px 玻璃胶囊（blur 8px + card 55% 底），对齐旧版 agent-turn-title。
- **自绘滚动条 + 消息导航** — 接入 `ScrollMinimap`（右侧自绘 thumb + 左侧鱼眼刻度 + minimap 面板），原生 webkit 滚动条整条隐藏（避开 Chromium 箭头按钮顽疾）。搬全 message-nav-* + scroll-progress-thumb CSS。
- **滚动位置记忆** — `ScrollPositionManager`（对齐旧版 useScrollPositionMemory）：切会话 useLayoutEffect + stopScroll + 直接设 scrollTop，无动画、无可见滚动过程；记忆每个会话距底距离，切回恢复不打断查历史。
- **ModelSelector** — 输入框尾部 Popover pill 选渠道（Cpu + 渠道名·模型 + ChevronDown），会话绑核后锁定。

## Bug 修复
- **会话页布局** — 滚不到底/输入框盖内容：改浮岛布局（消息区 absolute inset-0 + 输入区 absolute 底部），补 min-h-0 链。
- **TooltipProvider** — App 根补 TooltipProvider（ScrollMinimap 内部 Tooltip 缺 Provider 炸白屏）。
- **minimap 面板对齐** — agent 气泡撑满宽度右边贴面板右缘，和用户气泡右对齐；anchor 标示改为气泡变色（去描边去底色条）。
- **minimap items** — 按 user 分组带 replyPreview（之前只填 preview 导致助手气泡不渲染、全右对齐）。

## 其他优化
- **工程** — electron 加 `use-stick-to-bottom` devDep（ScrollPositionManager 用其 context）；globals.css 加几何 token + scene 背景 + scrollbar-none/thin；新建 agent-thread.css（精简）+ app-shell.css（composer）。

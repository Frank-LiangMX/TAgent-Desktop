# TAgent v2.0.0-dev.3 更新

本次预发布聚焦于会话工作台、协作流程和记忆系统的可用性：更稳定的多标签/分屏体验，更清晰的运行与通知反馈，以及在打包版中真正开始工作的自动记忆整理。

## 会话工作台

- **标签页管理** — 最多保留 4 个会话标签；新打开的会话会优先替换最早的非运行中标签。所有标签都在运行时会明确提示，而不是悄悄关闭会话。
- **自适应标签布局** — 标签可随可用空间收缩，避免右侧标签被裁切；默认宽度同步调整为更适合阅读标题的 120px。
- **分屏与切换稳定性** — 修复关闭标签或退出分屏后右侧留白、标签栏底板残影等问题；切换改为轻量淡入淡出，保留顺滑感而不干扰布局。
- **侧栏信息对齐** — 工作区计数、会话时间、轮数和运行状态重新对齐；运行中的状态点降低闪烁频率。
- **完成信息** — 助手回复底部的完成状态收束为更紧凑的状态行，复制等后续操作集中到右侧。

## 通知与协作

- **顶部通知中心** — 会话完成、运行中会话和班组状态可在顶栏呈现；通知支持进出动画、队列切换、展开查看全部与一键清除。
- **班组 / 会诊** — 顶栏班组入口可直接打开对应标签；会诊席位按设置中的模型配置生成，新增模型默认设置同步更新。
- **圆桌进行状态** — 每个席位会展示等待、运行、完成或失败状态，避免只看到第一个席位发言后不知后续进度。
- **进程可见性** — 会话内能展示仍在运行的后台 CLI 进程，并支持终止指定进程。

## 交互与外观

- **外观设置** — 正文字号与行间距改为独立预览容器，不再挤压设置页布局；字号档位、刻度和标签严格对齐，默认值恢复为“标准”。
- **会话引导与队列** — 引导使用带文字的折箭头，队列消息在会话停止后可立即发送；所有提示统一为主题化 Tooltip。
- **主题细节** — 修复思考强度扫光越界、工作区分组层次和通知栏左侧模糊等视觉问题。

## 记忆系统

- **自动整理在打包版启用** — 修复打包版默认关闭、且始终误判为前台繁忙的问题。空闲时会自动整理会话证据，不再只能依赖手动“提炼”。
- **KSCC 记忆模型回退** — 未配置外部 API 渠道时，自动整理改用已启用的 KSCC **DeepSeek V4 Flash**。
- **会话检索补齐** — KSCC 每轮可按当前问题检索相关历史会话摘要；当前会话自身会被排除，避免摘要回灌。
- **记忆图谱语义修正** — 图谱中的绿色节点实际是历史会话，现改名为“会话”，不再误标为 Skill。

## 修复

- 修复消息计时显示：超过 60 秒后显示为 `Xm Xs`，并避免思考时间与总运行时间错位。
- 修复关闭标签、悬停标签或切换分屏后出现白色底板/右侧空白的问题。
- 修复实时引导写入后未持久化、重开会话丢失的问题。

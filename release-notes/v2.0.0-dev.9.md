# TAgent v2.0.0-dev.9 更新

> 稳定性预发布版本。重点收口桌面会话体验、会话项目归属、自动化测试与安装包流水线。

## 新功能

- **无会话欢迎页** — 新建会话和打开项目的入口更清晰。
- **会话项目选择** — 多项目时显式选择新会话所属项目；会话创建后保持自己的运行目录。
- **真实渠道检测** — 支持 Anthropic、OpenAI Compatible 和 Google 协议的连接测试与模型列表拉取。
- **稳定性测试** — 新增会话持久化重载、Tab 项目归属、渠道响应解析、异常与超时测试。

## Bug 修复

- 修复归档抽屉内容穿透、文字与背景层叠以及折叠状态过强的问题。
- 修复全局“当前工作区”导致会话运行目录可能随界面状态变化的问题。
- 修复混用 Bun Test/Vitest、Jest DOM 未初始化和 UI alias 缺失造成的测试失败。
- 修复 Release 流水线缺少打包脚本、原生依赖重建和版本化发布说明的问题。

## 其他优化

- 会话侧栏改为工作区与时间线独立折叠，搜索和活动会话自动展开。
- 会话 hover 与选中态统一使用浮起阴影，不再添加额外左侧线条。
- 全仓测试统一到 Vitest；当前 24 个测试文件、252 条用例通过。
- CI 增加测试门禁和 Windows 安装包构建门禁。
- electron-builder 增加 Windows、macOS、Linux 产物配置。

## 已知问题

- MCP 管理界面和 HTTP/SSE MCP 真实连接测试将在后续版本完成。
- 子代理进度、父子消息嵌套和积极性设置仍待完善。
- 本地 Windows NSIS 最终安装器生成受外部工具下载网络超时影响；解包目录、ASAR 内容和原生模块已验证。

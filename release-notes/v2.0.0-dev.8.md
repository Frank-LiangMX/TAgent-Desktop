# TAgent v2.0.0-dev.8 更新

> 开发预发布版（dev.8）。两核工具循环完整接通 + 子代理（SubAgent）功能。
> 未打 tag、未触发 CI。仅供本地 dev 验证。

## 新功能

### 两核工具循环接通
- **Kscc 核接通** — session-service 传 `mcpServers`（getEnabledMcpServers）+ `canUseTool`（PermissionService.createCanUseTool）+ `permissionMode`（从 session meta 读，非硬编码 bypass）+ `allowDangerouslySkipPermissions: !canUseTool`。claude-agent-adapter buildSdkOptions 已透传。
- **Pi 核接通** — session-service 传 `mcpConfig`（buildMcpTools）+ `beforeToolCall`（PermissionService.createBeforeToolCall）+ `cwd` + `permissionMode`。pi-agent-adapter createSession 合并 mcpTools + 挂 beforeToolCall + kscc bare 传 descriptors + bashTool 用 `createBashTool(cwd)` 闭包注入工作目录。
- **权限模式运行中切换** — `UPDATE_SESSION_PERMISSION_MODE` IPC + SessionRuntime.setPermissionMode 委托 adapter（kscc 调 SDK query.setPermissionMode；Pi 靠闭包读 meta）。preload 暴露 `setSessionPermissionMode`。
- **PermissionService 白名单精确 key** — toolKey 含工具名 + 关键参数 hash（Bash:command 前缀 / Write+Edit:file_path），危险命令永不入白名单。
- **PermissionModeSelector** — 输入框 footer 三模式 Popover pill（auto/bypass/plan），Phosphor 图标，切会话持久化 + 通知运行时。

### 子代理（SubAgent）
- **Kscc 核子代理（SDK 原生）** — `agents` 选项传 SDK query + `forwardSubagentText: true` + `agentProgressSummaries: true`。SDK 自动处理 spawn/执行/结果收集。
- **Pi 核子代理（自实现）** — `task` 工具（`executionMode: 'parallel'` 支持并发）：创建子 Pi Agent（限制 tools + 自定义 prompt）→ 执行 → 收集文本结果 → 返回 tool_result。子 Agent 是内存实例，跑完即销毁。
- **内置子代理定义** — 3 个：code-reviewer（代码审查）/ explorer（代码库探索）/ researcher（技术调研）。参考 TAgent_General agent-prompt-builder.ts 架构。
- **模型路由** — Claude 渠道子代理用 haiku（便宜快速），非 Claude 渠道继承主模型。
- **System Prompt 委派策略** — 注入主 Agent system prompt，教何时委派子代理、有哪些内置子代理、委派最佳实践。
- **subagentEagerness** — 4 档积极性（never/conservative/balanced/aggressive），当前 hardcoded conservative，待接 UI 设置。
- **渲染嵌套（简化版）** — 子代理输出加左边框 + "子代理输出"标识，区分主 Agent 和 SubAgent。
- **task_* 事件转译** — sdkMessageToIR 新增 task_started/task_progress/task_notification system 消息转译。Chat.tsx 显示子代理启动（🔄）和完成（✅/❌）状态。

### pi-core 库
- **createBashTool(cwd)** — 工厂函数，创建带指定 cwd 的 Bash 工具实例（闭包注入，不读 process.cwd）。保留默认 bashTool 向后兼容。

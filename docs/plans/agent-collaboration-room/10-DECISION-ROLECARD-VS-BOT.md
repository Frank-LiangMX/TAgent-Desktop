# 决策：角色卡与 Bot 分层

> 日期：2026-08-21
> 状态：已确认

## 结论

现有角色库继续保留，并在同一个入口下增加同级的 Bot 页面：

```text
角色库
├─ 角色卡
└─ Bot
```

## 产品边界

- 角色卡是可复用的角色模板，保存职责、人格、系统提示词、边界和输出风格。
- Bot 是用户配置后长期存在的数字员工，可绑定角色卡，并拥有自己的模型、渠道、工具、权限和长期记忆。
- 角色卡可以创建 Bot，但 Bot 的修改不会反向修改角色卡。
- 融合会话添加成员时直接选择 Bot。
- 角色卡仍可用于一次性 Agent，不强制创建 Bot。

## UI 原则

- 保持一个“角色库”入口，不新增多个独立入口。
- 默认展示“Bot”页，因为 Bot 是日常使用对象。
- “角色卡”页主要承担模板管理和创建 Bot。
- Bot 的模型、渠道、权限和记忆等高级配置进入 Bot 详情页，不在列表页展开。

## 运行时影响

```text
RoleCard / RoleCardRevision
        ↓ 创建或绑定
BotProfile / BotConfigRevision
        ↓ 加入会话
RoomBotSeat / RoomAgentSession
```

Bot 绑定角色卡版本，而不是永远读取角色卡最新内容。已有 Bot 和历史房间不因角色卡更新而被无声改写。

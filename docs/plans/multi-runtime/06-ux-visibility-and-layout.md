## 1. 过程可见性原则（D12）

**要让用户看见，但两层披露：**

| 层 | 内容 |
| --- | --- |
| 主会话 | 简短进度：谁在跑、完成几席、结论摘要 |
| 点进去 | 该子运行完整过程（流式文本、工具行） |

**不要：** 纯黑盒只吐最终答案。  
**不要：** 主时间线同步刷多席全文。

对齐 Codex/Cursor：**主线干净，细节可钻。**

## 2. 统一「子运行 ChildRun」组件

```ts
purpose: 'subagent' | 'moa-seat' | 'kanban-worker'
```

| purpose | 主会话呈现 | 详情容器 | 是否进会话列表 |
| --- | --- | --- | --- |
| subagent | 折叠块 | 抽屉/侧滑 | 默认否 |
| moa-seat | 圆桌卡内一行 | 抽屉 | 默认否 |
| kanban-worker | 少刷；完成摘要回流 | 右栏任务 + 可选工人会话 | **可**（工人会话） |

可选 CTA：`在新对话中续聊此视角` → 再物化 session。

## 3. MoA 圆桌卡（示意）

**进行中：**

```
┌ 圆桌 · {标题} ─────────────────────┐
│ 2/3 席完成 · 汇总排队                │
│  · 架构师 (glm-5.2)  ✓             │ ← 可点
│  · 安全   (kimi)     …             │
│  · 汇总   (…)        等待           │
└────────────────────────────────────┘
```

**完成：**

```
┌ 圆桌完成 ──────────────────────────┐
│ ★ 综合结论（默认展开）               │
│ 各方发言 ▸ 点席位看全文              │
│ [按此建看板]  [复制]                 │
└────────────────────────────────────┘
```

入口建议：

- 输入区模式/动作：「会诊」  
- 自然语言 + **确认条**  
- 某条回复下「用会诊再议」（P1）

## 4. @ 讨论（Chat）呈现

- 气泡 **角色铭牌**（名 + 模型）  
- 发言在 **主时间线**，一般不需点进子会话  
- 若该轮触发只读 SubAgent：可嵌进度，回复仍落主线+铭牌

## 5. 看板 UX（D13）

### 5.1 相对 1.0

1.0 问题：左栏整页看板 + 会话团队整页 **双入口重复**（见 General `2026-07-16-kanban-digital-crew-ux`）。

### 5.2 Desktop 目标

```
主区：对话（队长）
右栏：本会话 board 班组/任务（有 board 才亮）
弱入口：全局「全部任务」（P2）
不做：独立看板大页作为默认主路径
远期：办公室沉浸层（非默认）
```

| 入口 | 优先级 |
| --- | --- |
| Work 内拆任务 | P0 |
| 右栏班组 | P0 |
| 完成回流对话 | P0 |
| 全局任务中心 | P2 |
| 独立大页主入口 | ❌ |
| 办公室 | 远期 |

交互：点任务 → 抽屉详情；工人完整对话勿塞窄右栏。

## 6. 布局与 react-mosaic（D15）

### 6.1 现状

`AppShell`：浮岛顶栏 + rail/sidebar + main。对话中心，非 IDE。

### 6.2 档 A（优先）

```
[rail|会话列表] | 对话 | 右栏（班组/文件/预览）
```

- 右栏可折叠；中右可拖宽  
- 库候选：`react-resizable-panels` 或自研 split  
- **不**替换 AppShell  

### 6.3 档 B（可选）

- **仅 main 内** 使用 [react-mosaic](https://github.com/nomcopter/react-mosaic) 做自由平铺（对话|看板|终端|预览）  
- 作为「工作台布局」增强，非默认  
- React 16–19 兼容；包名 `react-mosaic-component`  

### 6.4 不用 mosaic 的场景

- 全局导航 rail  
- 默认一打开四宫格  
- 用 mosaic 展示 MoA 席（MoA 用消息卡，不用窗格墙）

## 7. Chat / Work 控件位置

```
输入区附近或顶栏：
  协作 ( Chat | Work )     ← 仅用户可点
  权限（Work 下展开）

Agent 建议：
  消息内确认条，确认后系统切换
```

禁止五个权限/模式按钮横排无层级。

## 3. 已知坑 / 技术债

1. **工人「无文本输出」历史数据**  
   - 旧任务摘要可能仍是占位句；**新跑**应用增强抽取。  
   - 若仍空：查 Pi 流是否只产 tool 无 text、渠道 Key、工人 prompt。

2. **executionMode 热切换**  
   - kscc 长驻进程：切 Work 会 drop 再 spawn（resume）；Pi 热重建 tooling。  
   - 若仍无 kanban 工具：完整重启 app。

3. **`KanbanCrewStrip.tsx`**  
   - ~~底栏窄条实现仍在仓库~~ **已删除**（2026-08-03 P1；死代码无引用，样式无 CSS 残留）。

4. **右栏宽度固定**  
   - ~~约 300–400px，不可拖~~ **已可拖宽**（2026-08-03 P1；左缘手柄，280–560，localStorage 持久化）。

5. **@ 仅 Chat 注入角色 prompt**  
   - Work 下 `@` 不启多角色乱聊（文档 D11）。  
   - 多角色顺序靠 prompt，**非**真多进程轮转。  
   - followMode（activeSpeaker）已加：续聊无 `@` 仍由上一轮角色接，输入框顶部有指示条可 ✕ 退出。

6. **历史班组范围**  
   - `parentSessionId === 当前会话` 或 `meta.boardId`；无全局任务中心（P2）。

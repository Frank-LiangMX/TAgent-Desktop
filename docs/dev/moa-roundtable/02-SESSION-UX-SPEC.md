## 2. 历史注入

- 来源：面板 JSONL 近期 `user` / `assistant` 文本（跳过纯工具噪声优先）。
- 预算：合计字符上限默认 **12000**（可常量）；超限从最旧截断，保留近轮。
- 拼装：`[会话上下文]\n…\n[本轮议题]\n{prompt}` 喂给参考席与汇总席。
- 当前 user 消息先落盘再组历史时：**历史不含本轮刚写入的那条 user**（避免重复），或组完再 persist——实现选一种并单测。

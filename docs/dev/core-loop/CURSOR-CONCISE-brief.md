## 目标

```
[思考?] → [进度短总结] → [阶段工作块] → [进度短总结] → [阶段工作块] → [最终正文]
```

- 同阶段混族工具 → **一行**「编辑了 N / 探索了 M / 运行了 K」
- 阶段内思考 → 收进工作块展开，不刷「思考了片刻」
- 工具间 text → **进度短总结**（用户可叫停/引导）
- 尾部 text → 最终正文卡片

图二反例：逐条思考折叠 + 拆散工具行、无进度总结。

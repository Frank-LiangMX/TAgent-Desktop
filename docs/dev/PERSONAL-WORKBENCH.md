# 个人工作台怎么用

工作台用来管理工作、生活、知识和灵感。先放进来，再按需要整理，无需先决定属于哪个模块。

## 从五个入口开始

| 入口 | 用途 |
| --- | --- |
| 今天 | 随手记内容，查看待办和当天日程 |
| 收集 | 找到原文与 Agent 整理稿，搜索、加标签或存入知识库 |
| 日程 | 在周/月日历里安排待办、独立时间段，查看自动任务的下次触发 |
| 知识 | 跨库搜索文档和标签，阅读、编辑长期积累的内容，管理知识库与来源 |
| 回顾 | 月历查看每日足迹，或切换工作日报、让 Agent 回顾这周 |

待办完整列表、工作记录与自动化在「更多」里。知识库统一从工作台「知识」进入，应用侧栏不再提供重复入口。会话中的知识库管理按钮和文档来源引用也会打开工作台，并定位对应知识库与文档。

「知识」首页展示知识库、主题标签分布与最近更新的文档，可按标题、正文、标签跨库搜索。进入知识库后，左侧查找和选择文档，右侧阅读或编辑；窄屏改为上下布局。新建、文件和云文档导入、目录来源管理、分享包导入导出继续使用已有存储与接口。编辑时切换文档、返回首页或离开知识页，会先检查未保存修改。

## 直接从图形入口操作

- 「今天」的环形图展示当前项目全部待办的完成比例，点击未完成或已完成可打开相应列表。无待办时显示创建入口，不显示虚假的完成比例。
- 周日程按周一到周日排列，点击日期查看当天安排；左右箭头切换周。跨天日程显示在覆盖的日期上，到期待办单独标注。
- 「收集」默认展示卡片，点「新增收集」展开输入；收起输入仍保留草稿。分类入口可筛选随笔灵感、链接资料和工作进展，卡片可展开全文。
- 「回顾」默认打开每日足迹：左侧月历显示有记录的日期，右侧展示当天笔记、实际完成、成果和明确标为计划的安排。切换「工作日报」查看七天统计和日报版本。

图表跟随项目筛选。记录统计仅含未归档内容，回收站不参与；链接与工作进展重叠时归为工作进展，每条只计入一类。图表由本地已保存数据计算，不生成模拟统计，也不推算工作时长或生活效率。

## 随笔和灵感

在「今天」写下想法，直接点「记下」。例如「今天散步时想到，可以把读书笔记按问题组织」。标题、标签和项目都可留空。

需要整理时，点「保存并整理 → 整理随笔与灵感」。原文先保存，再打开 Agent 会话草稿；发送后才开始整理。整理稿保存到「收集」，原文仍保留，可点「查看原始收集」核对。

## 待办和日程

输入「明天下午三点到三点半整理旅行攻略，这周还要预约体检」，点「保存并整理 → 整理成待办 / 日程」，再发送 Agent 请求。行动保存为待办，可设置计划日期和具体时间，直接进入日历。独立时间段保存为日程，可关联已有待办；时间有歧义时需要进一步澄清。

也可以直接点击「新增待办」或「安排时间」，手动保存。新建待办默认「个人安排」；选择「工作事项」后，其完成记录才进入日报。个人安排不会混入工作成果。

待办标题可打开编辑器设置「计划日期」和可选时间：仅有日期的显示在周视图顶部，具体时间显示为计划时点，不代表持续时长，也不会重复创建日程。点击待办右侧日历图标可为它安排独立时间段，关联现有待办并继承项目。日程可修改起止日期/时间、解除关联或删除；排期与删除日程均不改变待办完成状态。修改待办项目时，关联日程跟随项目并递增版本，旧编辑草稿会提示冲突。

「日程」提供按小时排列的周视图和月视图；点击空白小时或「新建日程」添加时间段，点击条目编辑。月视图最多展示三项，其余在下方所选日期的完整安排中查看。窄窗口周视图显示所选一天，月视图以类型标识呈现，选择日期后查看详情。已完成待办默认隐藏，可勾选显示。

自动任务复用现有调度器，只显示启用任务已确定的下一次触发，点击打开原自动化页面，不推算未来重复项。自动任务没有工作台项目归属，仅在「全部项目」下显示。加载失败不影响本地日历。

目前日程只在本地工作台展示，没有到点通知，也不会同步到 WPS。Agent 工具支持新增，已有条目的编辑、删除、勾选完成通过界面操作。

## 收集一组链接

粘贴网页地址或带地址的分享文案，支持一段文字里放多个 HTTP(S) 链接。点「保存并整理 → 提炼链接核心信息」，再到 Agent 对话发送。

Agent 用内置浏览器读取页面正文，提炼要点并保留来源链接，结果作为新记录回到「收集」。有长期价值时，从记录菜单点「入知识库」，选择现有知识库确认保存。

## 多条资料逐步形成个人知识

1. 在「收集」勾选相关笔记或链接，点「整理所选」。
2. 在 Agent 对话发送草稿；Agent 读取全部来源，归纳共同观点、分歧和不确定项，保存一条有主题标签的新笔记。
3. 整理稿上的「查看原始收集 1 / 2 …」可核对全部来源；「同标签笔记」按共同标签显示最多五条相关记录，不是语义搜索。
4. 有长期价值时点「入知识库」，选择知识库、核对标题和主题标签，再确认。原文与整理稿保留，知识文档保留来源笔记 ID 和版本。

这版支持多条资料合并为新的主题知识。自动持续改写既有知识文档、差异审核和语义地图尚未实现。

## 标签如何贯通

原始随手记录允许暂不分类；保存的 Agent 整理成果必须至少有一个主题标签，工具与存储都会校验。优先复用适用的来源标签，也可以编辑补充，例如 `产品/交互`、`阅读/方法`。待办、日程和日报编辑器也有标签输入。

工作台顶部的「标签筛选」贯通笔记、待办、日程、日报和每日足迹。选择 `产品` 同时包含 `产品/交互` 等子标签。知识文档入库保留标签；知识库页面可查看、编辑标签，并按标签关键词检索，分享包导出/导入也保留标签。旧资料不会被随意补造主题；旧分享包中无标签的 Agent 文档明确标为「未分类/历史导入」。

## 过几个月如何知道某天做了什么

打开「回顾 → 每日足迹」，用月历翻到那一天，可按项目、主题标签或关键词筛选，并切换「实际记录 / 计划安排」。完成、重新打开、笔记编辑、日程修改/取消、工作台入库和日报保存都有独立快照；后续修改不抹掉已经保存的历史。日报重新汇总仍使用当天的实际完成快照，次日重新打开待办不会删掉前一天的成果。

笔记按填写的发生日期归档，没有具体时刻就显示「未标具体时间」；补记和后续修改会另标实际记录/更新时间。计划明确标为计划，不估算实际工时，也不当成完成证明。

页面说明详细历史从何时开始。升级前只保留尚可核实的正文、当前完成事实和已有日报，不重建从未保存的旧版本。从收集入库会产生知识足迹；在「知识」页面直接新建、导入或编辑文档，当前不全部纳入每日足迹。

Agent 可用 `workbench_history` 按日期范围检索快照，再引用来源整理回顾。读取本地足迹无需模型或联网；自动提醒、跨设备同步及历史版本恢复另行实现。

知识库文档写入现默认可用，Agent 提议入库仍需用户确认。部署方可用 `TAGENT_ENABLE_KB_WRITES=0` 显式关闭。入库成功但足迹保存失败时，会明确提示；再次确认复用同一来源版本的文档，补记足迹而不重复建文档。

抖音、小红书等页面可能要求登录、限制读取或只提供标题和评论。读取不到正文时应说明失败；当前没有视频音频转录，不能把页面简介当成整段视频总结。可以补充自己的文字摘录后再整理。

## 工作记录与回顾

记录实际完成的工作时，先选「工作进展」，例如「完成登录接口联调，发现两个待修问题」。日报汇总这些记录和完成的工作事项，生成可修改的本地草稿；它本身是规则汇总，不是 AI 总结。

在「回顾」点「让 Agent 回顾这周」，可根据本周的工作、生活安排和灵感记录整理回顾。也可以在对话里说「找出最近关于旅行的笔记，列出还没处理的想法」。Agent 可检索工作台，不需要反复复制原文。

## 执行与保存

- 「保存并整理」会准备会话草稿，发送后才调用模型；已有草稿时会复制整理请求并提示粘贴。
- Work 模式可新增整理稿、待办和本地日程；Chat 模式只读，只提供建议或草稿。
- 保存成功后才应声称已写入；未能读取链接或来源不足时，应明确说明缺口。
- 不会因记录了生活随笔就自动纳入工作日报，也不会把所有笔记自动写入知识库。

本轮增加了主进程 Agent 工具，正在运行的旧应用需重启加载。真实 Electron 验收使用本地合成页面与模拟整理稿，已验证正文读取、工具保存和界面更新；尚未验证真实模型对抖音、小红书的完整处理。

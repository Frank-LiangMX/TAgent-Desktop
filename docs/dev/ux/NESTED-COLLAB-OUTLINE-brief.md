# 设计：长会话内嵌套行为快速回看

> 日期：2026-08-11  
> 状态：方案草案（未实现）  
> 问题：一场长会话里混有会诊、圆桌、子代理、班组时，时间线很长，难快速定位这些「主会话内嵌套」的协作块。

## 1. 问题本质

嵌套行为**已经在时间线里**（入口卡 / 任务卡 / 班组回流），缺的是**目录索引**：像文档大纲，而不是再造一套平行聊天。

## 2. 推荐方案：协作目录（Session Collaboration Outline）

在消息区上方或左侧加一条**轻量目录条**（非第二套会话）：

```text
[全部] [会诊 2] [圆桌 1] [子代理 4] [班组 3]
────────────────────────────────
• 会诊 · 架构评审 …… 14:02  → 点击滚动到卡
• 圆桌 · 方案收敛 …… 14:18
• 子代理 · 探索仓库 …… 14:22
• 班组 · 实现登录 …… 14:40
```

### 数据源（已有，几乎零新协议）

| 类型 | 现成信号 | 跳转锚点 |
|------|----------|----------|
| 会诊 | `DisplayItem.moaRoundtable` | `data-moa-id` / key |
| 圆桌 | `DisplayItem.moaDiscussion` | discussionId |
| 子代理 | `taskCard` / SubagentEntryCard | parentToolUseId |
| 班组 | kanban 回流 notice / board 事件 | taskId / boardId |

渲染层扫 `items` 建索引即可；不必改 JSONL 协议（可选后期写旁路索引加速）。

### 交互

1. **芯片筛选**：点「圆桌」只高亮/置顶目录里圆桌项（时间线可淡化其它，或仅目录过滤）。  
2. **点击跳转**：`scrollIntoView` 到对应卡，短暂高亮。  
3. **进行中角标**：running 脉冲，与侧栏色点一致。  
4. **空态**：本会话无嵌套则不显示目录（零打扰）。

### 不做（避免过重）

- 不做独立「协作会话」树替换主时间线。  
- 不把子代理全文再镜像一份到目录。  
- 不与 ScrollMinimap 刻度抢职责：刻度=用户轮次；目录=协作机制。

## 3. 备选（次优）

| 方案 | 优点 | 缺点 |
|------|------|------|
| B. 仅增强 minimap 色块类型 | 少 UI | 难读标题，嵌套语义弱 |
| C. 右侧「协作抽屉」 | 空间大 | 多一层面板，Discoverability 差 |
| D. Cmd+K 搜「类型:圆桌」 | 强力 | 短路径不如目录直观 |

## 4. 落地切片建议

1. **S1**：只读索引 + 顶栏芯片 + 点击跳转（会诊/圆桌/子代理）。  
2. **S2**：班组任务 + running 角标。  
3. **S3**：筛选淡化时间线 + 键盘上下跳转。

## 5. 与设置页关系

圆桌/班组设置管**默认策略**；本目录管**本场回看**。二者正交，可并行。

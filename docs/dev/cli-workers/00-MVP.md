# 本地 CLI 工人 · 使用说明

子代理可选用本机 coding CLI。默认关闭；开启后形成 **启用池 + 优先级**，主会话可挑选。

## 开启

1. **设置 → Agent 行为 → 子代理**
2. 默认后端选 **本机 CLI**
3. **启用**要用的工人；用 ↑↓ 调优先级（列表越靠上越高）
4. 需要时再点 **检测本机**（不进页强扫）
5. 路径 / 模型在「高级」里改

## 挑选规则

1. 主 Agent `task` 参数 **`cli`**（如 `kscc` / `grok`）若启用且本机可用 → 用之  
2. 否则按启用列表 **数组顺序** 试，第一个本机可用者胜出  
3. 池空或全不可用 → 回退 **内置（进程内）**  

同会话 **`task` 支持 parallel 多路**：每路独立 spawn，可同时跑，且可各指定不同 `cli`。

## 使用

- 在 **外渠 / Pi 核** 会话里让主 Agent 用 `task` 派子代理  
- 主会话保留：派过（tool_use）+ 结论（tool_result）  
- 详情：打开时可看过程；过程可不依赖永久落盘  

## 不做

- Hermes / OpenClaw 等编排类  
- 把每个 CLI 做成主会话内核  

## 切片

| 切片 | 内容 |
|------|------|
| 1 | 配置 / IPC |
| 2 | kscc runner + task |
| 3 | 设置页 |
| 4 | grok / codex / mimo |
| 5 | 启用池 + 优先级 + task.cli 挑选（去硬默认） |

配置文件：`~/.tagent[-dev]/cli-workers.json`  
`defaultCliId` 仅兼容旧文件，保存时同步为第一个 enabled。

## 0. 一句话总结

把本机 coding CLI（**kscc / grok / codex / mimo**）做成 **L1 短命子代理工人**（不是第二个主会话内核）：配置 + IPC + 多协议 runner + 设置页；`task` 可并行多路，按 **启用池 + 列表优先级 + 可选 `task.cli`** 挑选；失败回退 **内置（进程内）** 子代理。设置侧栏 **Agent 行为** 升为大类（与核心/高级同级），下挂 **会诊 / 子代理 / 班组 / 圆桌**。  
**已提交并 push**：`f16ef90` → `origin/main`（2026-08-10）。

## 1. 背景与讨论脉络

1. 用户希望本地 agent CLI 当**透明子代理**（可见输入/过程，非黑盒 shell）。
2. 范围：仅 TAgent；异构协议统一到 invoke/observe；多用户环境靠本机探测，不写死 PATH。
3. 排除编排类 CLI（Hermes / OpenClaw）——避免嵌套「导演」。
4. 双核（Pi / kscc）仍是 **L0 主运行时**；外部 CLI 只做 **L1 短命工人**。
5. MVP → 多 CLI → 手动探测 → 进程树 kill → 设置 IA 拆页 → **去掉硬默认 CLI，改启用池+优先级+`task.cli`**。
6. 命名纠偏：原「圆桌 · 快速」实为并行交卷 → 用户可见名改 **会诊**；互相对话才叫 **圆桌**；「本地 CLI 子代理」页改 **子代理**（内置+本机 CLI 同页）。
7. 对照探索：kscc 子代理只读摸了 `F:\hermes-studio` 多 runtime / `runAndWait` / 委派；TAgent 更极端（短命 spawn，不长驻 pty）。**能力画像（cost/vision）设计已讨论，代码未做**。

## 3. 已交付能力

### 3.1 CLI 工人运行时

| 能力 | 说明 |
|------|------|
| 配置 | `~/.tagent[-dev]/cli-workers.json` 扁平 v1；seed 四工人；`ensureSeedWorkers` 补缺 |
| 总开关 | `enabled` + `defaultBackend: 'in-process' \| 'cli'` |
| 启用池 + 优先级 | `workers[]` **数组顺序 = 优先级**；启用才进池 |
| 挑选 | `task.cli` 指定 → 否则按序第一个 **本机 bin 可用**；全挂 → in-process |
| 并行 | `task` 工具 `executionMode: 'parallel'`；每路独立 resolve/spawn |
| 协议 | kscc stream-json；grok/codex/mimo NDJSON observers |
| Windows prompt | 避免 `cmd /c` 重分词；node 直连 / stdin（见 `run-kscc-worker`） |
| 生命周期 | AbortSignal + 进程树 kill（Windows `taskkill /T`）+ 默认 20min 超时 |
| 探测 | 设置页 **手动**「检测本机」；进页不自动扫 |
| 黑名单 | id/bin basename：`hermes` / `openclaw` |
| 兼容字段 | `defaultCliId` 仍落盘，保存时 `syncDefaultCliId` 同步为第一个 enabled；**运行时不硬绑** |

### 3.2 设置页

- **子代理**页：委派积极性（全局默认 localStorage）+ 默认后端（内置 / 本机 CLI）  
- 仅「本机 CLI」时展示工人池：启用、↑↓ 优先级、探测、高级路径/模型  
- **内置**时不展示 CLI 列表  

### 3.3 委派积极性

- 会话 meta `subagentEagerness` 仍 per-session  
- 全局默认：`subagentEagernessDefaultAtom`（`tagent:subagentEagernessDefault`）  
- 会话未设过时：用全局默认并落盘一次，保证主进程注入一致  

### 3.4 其它同批（commit 内）

- 子代理详情 rehydrate / 耗时 / 流式过程  
- streaming-delta 协议、smooth stream 节奏等聊天侧配套

## 6. 架构决策（勿轻易推翻）

1. **L0 vs L1**：主会话仍是 Pi/kscc 双核；CLI 只当 task 工人，不做成第三个 sticky 内核。  
2. **短命 spawn**：一次 task 一次进程，不做 Hermes 式长驻 pty + 空闲回收（更省、边界清）。  
3. **可见性**：主线保留派过 + 结论；详情过程可 partial，不强制长期落盘全量 stream。  
4. **挑选**：显式 `cli` > 启用池优先级（bin 可用）> 内置；不再唯一 `defaultCliId`。  
5. **探测手动**：设置进页不扫 PATH，避免卡顿。  
6. **deny 编排 CLI**：hermes/openclaw 配置层拒写。

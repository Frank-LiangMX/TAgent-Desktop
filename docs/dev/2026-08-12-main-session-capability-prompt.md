# 主会话能力地图 · system prompt（2026-08-12）

## 目标

主会话须知悉：子代理、班组（看板）、会诊、圆桌的**存在、场景、谁发起**；
对自身无法调用的入口（会诊/圆桌），用自然语言建议用户从发送旁 ▾ 进入。

## 契约

| 能力 | 发起方 | Chat | Work |
|---|---|---|---|
| SubAgent | 主会话工具 | 禁止；建议切 Work | 可委派（另有委派段） |
| 班组/看板 | 主会话 `kanban_*` | 禁止；建议切 Work | 可创建/派工 |
| 会诊 | **用户**发送旁 ▾ | 可建议 | 可建议；**不可**自称已会诊 |
| 圆桌 | **用户**发送旁 ▾ | 可建议 | 可建议；**不可**自称已开圆桌 |

## 改动

- `execution-mode-prompt.ts`：Chat/Work 均加「协作能力与建议入口」段
- 同步单测断言关键关键词

## 验收

1. Work prompt 含会诊/圆桌场景 +「请用户点发送旁 ▾」
2. Chat prompt 含切 Work（派工/改码）与会诊/圆桌建议
3. 明确禁止假装已开会诊/圆桌
4. 既有 Chat 硬拦 / Work 看板步骤仍保留
